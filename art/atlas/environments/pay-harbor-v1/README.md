# Pay Harbor v1

Pay Harbor is the first physical learning district for SFACE. Its native
procedural scene turns the Last Lantern lesson into a walkable route: meet
Mara, inspect the lantern counter, review a payment, carry the relay, install
six stations, and see the ferry route reopen.

`build_scene.py` imports only the approved Atlas Walker primitive helpers and
the Beacon Commons procedural scene writer. It reads no image, texture, stock
asset, scan, or external mesh.
