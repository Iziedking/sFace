## Longer description

```text
NIM Atlas is a Nimiq Pay Mini App game about a city whose payment routes have
stopped working. Choose Explorer or Builder, follow the route through Beacon
Commons, and help residents restore the systems they rely on.

The first mission, The Last Lantern, teaches the payment path through play:
Ask, Check, Approve, Confirm, and Unlock. The game explains NIM and Lunas when
the player reviews the exact request. Practice mode uses a local fixture and
never sends NIM, so anyone can learn the system before connecting a wallet.

Daily Atlas puzzles, the Living Knowledge Book, and a deterministic Core Run
give the game reasons to return. Competitive and reward paths are optional
server capabilities and are labelled according to their verified state.
```
