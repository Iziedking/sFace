# NIM Atlas launch copy

NIM Atlas is a short adventure game about a city whose payment routes have
stopped working. You walk to the problem, choose what to inspect, and repair
the route by using the right Nimiq evidence.

The first mission follows Mara's Last Lantern. You review a readable request,
learn why NIM is measured in Lunas, and wait for the matching network record
before the harbor opens.

Practice mode is free and wallet-free. Optional TestAlbatross payment,
competitive verification, and reward paths are clearly labelled and remain off
until their deployment gates are complete.

## Demo clip order

1. Show the welcome screen and explain Explorer versus Builder.
2. Walk through Beacon Commons with the map and distance card visible.
3. Meet Mara and review the network, recipient, and Lunas.
4. Show the Builder prediction trial.
5. Finish the Core Run and show the honest local or server result state.

Only show a real wallet approval or reward result if the matching owner gate
has been completed and the evidence can be inspected.
